Quick fixes for Google Ads, tracking, Excel reports and landing pages.

  1. Open the ad's website link in your browser on both phone and computer.
  2. If the page shows an error (such as 404), correct the link or restore the page.
  3. Update the final URL in your ad and resubmit it for review.
Escalate if: the ad is disapproved again after the page loads correctly.

  1. Check that the campaign status is Enabled and not paused by a schedule or rule.
  2. Check that the daily budget is above zero.
  3. Check that the ads are approved and the payment method is active.
Escalate if: everything looks correct but there are still no impressions after 24 hours.

  1. Open Ads & assets and check the status of each sitelink.
  2. If a sitelink is unapproved, read the reason, edit the text or link, and resubmit.
  3. Make sure at least two sitelinks are active; extensions do not show every time.
Escalate if: sitelinks are approved but never appear after several days.

  1. Check the conversion action status in the account (Recording, No recent conversions, or Unverified).
  2. Confirm the tracking tag is still on the thank-you page; site updates can remove it.
  3. Make a test conversion and check it appears after a few hours.
Escalate if: the tag is present but conversions still do not record.

  1. Check whether the conversion tag is installed twice on the confirmation page.
  2. Check that the conversion action counts "One" (not "Every") for lead-type goals.
  3. Remove the duplicate tag and run a test purchase.
Escalate if: the tag is managed by a web team, so they can remove it.

  1. Look for extra spaces before or after the text in the lookup column.
  2. In a helper column, use =TRIM(A2) and fill down.
  3. Use the cleaned column and set the last VLOOKUP argument to FALSE for an exact match.
Escalate if: the errors remain after trimming.

  1. Right-click the pivot table and choose Refresh.
  2. Click a cell in the source data and press Ctrl+T to make it a Table so new rows are included.
  3. Refresh the pivot table again.

  1. Check for duplicate rows: Data > Remove Duplicates.
  2. Confirm both use the same date range and currency.
  3. Check that your SUM range covers all the rows.
Escalate if: the totals still differ after these checks.

  1. Check that the page's <head> contains this line:
    <meta name="viewport" content="width=device-width, initial-scale=1">
  2. Save and refresh the page on your phone.
  3. Test again using Chrome DevTools (F12, then the phone icon).

  2. Make sure the image file was uploaded to that folder.
  3. Reload the page while holding Shift to clear the cached version.
